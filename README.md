# Meeting Minutes Generator

A simple AI-assisted tool to convert raw meeting notes written in Bahasa Indonesia (`.txt`) into professionally formatted Microsoft Word documents (`.docx`).

Uses a predefined Word template (`notula.dotx`) to ensure consistent document formatting.

## Project Structure

- `AGENTS.md` – Instructions for the AI on processing and converting meeting notes.
- `README.md` – Project documentation.
- `notula.dotx` – Word document template.
- `raw/` – Raw meeting notes (`.txt`).
- `docs/` – Generated Word documents (`.docx`).
